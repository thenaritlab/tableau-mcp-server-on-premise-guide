# Tableau Server On-Premise + Tableau MCP + AI — bilingual guide

Static site. Open `index.html` in a browser, or serve the folder with any web server
(`python3 -m http.server 8000` then http://localhost:8000).

- `index.html` — landing page with TOC, section descriptions and read times for both languages
- `en/` — 9 English pages · `th/` — 9 Thai pages (same order, language switcher on every page)
- `assets/` — stylesheet and script (copy buttons, dark mode, reading progress, mobile menu)

Created by The Narit Lab. All host names, tokens and company names are placeholders.
